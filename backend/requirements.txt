# Upper bound is load-bearing, not cosmetic. NumPy 2.0 changed the C ABI, and
# the pinned binary wheels in this file (faiss-cpu 1.8.0, chromadb 0.5.15,
# scikit-learn 1.5.2, sentence-transformers 3.1.1) are built against NumPy
# 1.x. Resolving numpy 2.x produces the "compiled using NumPy 1.x cannot be
# run in NumPy 2.x" ImportError at startup — i.e. a Docker image that builds
# successfully and then crashes on first request. Raise this deliberately,
# after re-pinning the wheels above.
numpy>=1.26.0,<2.0
